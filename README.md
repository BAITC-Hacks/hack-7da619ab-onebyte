# Meeting AI

MVP системы автоматического протоколирования совещаний для Самрук-Казына.
Python + FastAPI, обычные HTML, CSS и JavaScript. Node.js и сборка frontend не нужны.

## Запуск

Нужен Python 3.10 или новее. Из корня проекта:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

Откройте http://127.0.0.1:8000. На Linux используйте `.venv/bin/python`.
Если Python доступен через Windows launcher, вместо `python` используйте `py`.

Если зависимости уже установлены, достаточно `python app.py` (или `py app.py`).
Этот способ запуска явно выбирает каталог проекта, порт 8000 и включает
автоматический перезапуск при изменениях Python-кода.

### Если вместо страницы отображается старый JSON

Остановите прежний Uvicorn через `Ctrl+C` в терминале, где он был запущен,
и запустите приложение заново командой выше. Уже работающий процесс без
`--reload` продолжает использовать ранее загруженный Python-код.
Ошибка «address already in use» означает, что порт 8000 ещё занят; новый
экземпляр в этом случае не запустился. После перезапуска обновите страницу.

Маршрут `GET /` отдаёт **`templates/index.html`** с типом `text/html`.
CSS и JavaScript доступны по `/static/css/styles.css` и `/static/js/app.js`.
Пути вычисляются относительно `app.py`, а не рабочего каталога терминала.
Корневой `index.html` — отдельный старый макет, он не используется сервером;
для изменения интерфейса редактируйте `templates/index.html`.

## Возможности

- Русский адаптивный интерфейс с выбором и перетаскиванием одной записи MP3, WAV, M4A или MP4.
- Имя и размер выбранного файла, удаление выбора, проверка расширения и пустого файла.
- Кнопка «Обработать запись» показывает сообщение о том, что обработка ещё не подключена.
- Вкладки «Саммари», «Поручения», «Транскрипт», включая переключение стрелками, Home и End.
- Заготовка таблицы поручений и отключённые кнопки экспорта PDF/DOCX.

Результаты не генерируются. STT, диаризация, LLM, интеграции встреч, авторизация и экспорт не реализованы. AI API и модели не подключены.

## Локальность данных

Файл остаётся в памяти браузера: не загружается на сервер, не сохраняется приложением и не отправляется во внешние сервисы. Проверка расширения служит удобству интерфейса и не проверяет содержимое файла. Backend отдаёт страницу и локальные статические ресурсы; внешние шрифты, CDN и аналитика отсутствуют.

Структура подходит для дальнейшего развёртывания on-premise. Будущие обработчики и модели должны работать внутри локального контура; сейчас API загрузки и обработки отсутствуют. Аудио/видео и каталоги будущих результатов исключены из Git через `.gitignore`. Реальные транскрипты и чувствительные документы также не следует добавлять в репозиторий.

## Структура

```text
app.py                     # FastAPI: главная страница и /static
templates/index.html       # Разметка
static/css/styles.css      # Оформление и адаптивность
static/js/app.js           # Выбор файла, вкладки, заглушка обработки
requirements.txt           # FastAPI и Uvicorn
.gitignore                 # Python и локальные данные
```
